
# Online Store Sales Analysis


This project analyses sales data from a fictional online store using SQL. The purpose is to understand sales performance and identify useful business insights.


- SQL
- SQLite
- Visual Studio Code


The dataset contains 12 sales records with information about:
- Order dates
- Customers
- Cities
- Products
- Categories
- Quantities
- Unit prices


The project answers the following questions:

1. What is the total revenue?
2. Which products sold the most?
3. Which city generated the highest revenue?
4. What is the average order value?
5. Which month had the highest revenue?


- Total revenue: 16,330 SAR
- Best-selling product: Mouse (6 units)
- Highest revenue city: Riyadh (7,770 SAR)
- Average order value: 1,360.83 SAR
- Highest revenue month: March 2026 (4,540 SAR)


This project helped me practise SQL queries and understand how sales data can be used to analyse business performance.
